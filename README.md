# 🧹 Ultimo

### Деинсталлятор и очистка системы для Windows

*Удаляет программы начисто — вместе с хвостами, которые обычные деинсталляторы бросают в реестре и на диске.*

## 🤔 Зачем это нужно?

Удалил программу через «Параметры» → а она оставила после себя:
- 📁 папки в `AppData`, `ProgramData`, `Program Files`
- 🔑 ключи в реестре
- 🚀 запись в автозагрузке
- 🧩 расширение в браузере

Через год такого — система еле дышит. **Ultimo** сносит программы вместе со всем мусором и показывает, что именно удаляет.

## ✨ Что умеет

### 🗑️ Удаление программ
| Режим | Что делает |
|---|---|
| 🗑️ **Обычное** | Запускает штатный деинсталлятор |
| ⚡ **Тихое** | Без окон и вопросов (если программа поддерживает) |
| 🧹 **Мастер удаления** | Удаляет → сам находит хвосты → предлагает вычистить |
| 💥 **Принудительное** | Для битых установок: сносит папку и ключ напрямую |
| ☑️ **Пакетное** | Отметил галочками десяток — снёс разом |
| ✖️ **Убрать из списка** | Программы уже нет, а строка висит? Уберём только запись |

### 🎯 Режим охотника
Не знаешь, как называется программа? **Наведи курсор на её окно** — Ultimo сама определит, что это, и найдёт в списке. 

### 🛰️ Монитор установки
Самая мощная штука. Запускаешь установщик **через Ultimo** и видишь **в реальном времени**:
```
＋ создано: C:\Program Files\SomeApp
＋ создано: C:\Program Files\SomeApp\app.exe
🔑 ключ создан: HKLM\SOFTWARE\SomeApp
⏳ Идёт установка, отслеживаю… (изменений: 47)
✓ Изменений больше нет — установка завершена.
```
А потом — **↩️ одна кнопка отката**, которая удаляет ВСЁ, что наделал установщик. Передумал ставить программу? Система будет как до неё.

## 🚀 Запуск

```bash
git clone https://github.com/ultimate390/ultimo.git
cd ultimo
pip install PyQt5
python main.py
```

> ⚠️ **Запускай от имени администратора** — иначе не будет доступа к `HKEY_LOCAL_MACHINE`, системным программам и службам.

---

## 📦 Сборка в .exe

Проект — **один файл**, собирается элементарно через [auto-py-to-exe](https://pypi.org/project/auto-py-to-exe/):

```bash
pip install auto-py-to-exe
auto-py-to-exe
```

Настройки:
| Параметр | Значение |
|---|---|
| Script Location | `main.py` |
| Onefile | **One File** |
| Console Window | **Window Based (hide console)** |
| Icon | `icon.ico` |
| Advanced → Version File | `version.txt` |
| Advanced → Name | `Ultimo` |

Готово — на выходе `Ultimo.exe` 🎉

---

## 🎒 Портативный режим

Положи пустой файл `portable.txt` рядом с `Ultimo.exe` — настройки будут храниться там же. Кидай на флешку и носи с собой, установка не нужна.

---

## 🖱️ Интеграция в Windows

При первом запуске Ultimo добавляет в контекстное меню установщиков пункт **«Установить через Ultimo»** — правый клик по `.exe` или `.msi`, и установка сразу отслеживается.

> 💡 На **Windows 11** пункт лежит в «Показать дополнительные параметры». Отключить можно в Настройках.

---

## ⚠️ Дисклеймер

Принудительное удаление, откат установки, шредер и очистка — **необратимы**. Защита от сноса системных каталогов (`C:\Windows`, `Program Files` и т.п.) встроена, но голова всё равно нужна. Тестируй на некритичных программах, а перед большой чисткой жми 🛡️ «Создать точку восстановления».

Проект в статусе **0.9 Beta** — баги возможны. Нашёл? [Заводи issue](https://github.com/ultimate390/ultimo/issues) 🐛
